
# Cortex-M3 RTOS Scheduler

This project implements a minimal RTOS-style round-robin scheduler for ARM Cortex-M3 processors from scratch.

Features implemented so far:

✓ Bare-metal startup code
✓ Custom linker script
✓ Makefile build system
✓ SysTick timer configuration
✓ SysTick interrupt handler

Upcoming features:

- Task Control Block (TCB)
- Per-task stack allocation
- Context switching
- Round robin scheduler
- PendSV based switching
